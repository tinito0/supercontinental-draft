## What already holds

- Every data view has empty, loading and error states (R-27): match, list, timeline, stats, shots, lineups.
- No invented numbers (R-17): xG, shot map and ratings are declared unavailable instead of filled; dominio is labelled
  as a model with its weights. Same for possession when the game did not count it.
- One accent; home = accent, away = neutral, used the same way in every chart and list.
- Touch targets: tabs, shot rows, player rows and sort buttons have `min-h-11`.
- The live score flashes once on a goal only (`value-flash`), not on page open. Reduced motion is respected globally.

## HIGH (Hard Gate)

**F-01 · R-17/C-5 · Stale claim about possession.** `MatchStatSections.jsx:86` says "La posesión no aparece porque
todavía no se mide", but `utils/matchStats.js:112` shows it whenever the game counted it [read]. A reader sees
possession in the table and a note saying it does not exist. Fix: "La posesión aparece solo cuando el juego la contó."

**F-02 · R-32 · Tabs without panels.** `components/ui/Tabs.jsx` renders `role="tab"` with no `aria-controls`, and the
match page renders the content without `role="tabpanel"` [read]. Screen readers announce tabs that control nothing.
Fix: `id`/`aria-controls` on each tab and a `role="tabpanel"` wrapper with `aria-labelledby` in the match page.

## MEDIUM (Purpose-Gate)

**F-03 · C-3 · Shot detail repeats the row.** Clicking a shot (`ShotsPanel.jsx`) opens a box with player, minute and
result, all already in the row; only "Tipo" is new and "(penal)" is already in the name [read]. The click does
nothing useful. Fix: drop the detail box and the pressed state; or keep it only once shots carry a location / xG.

**F-04 · C-1 · Three different "Los que más" / leaders.** Player leaders exist per match (`PlayerAnalysis`), the
tournament has hand-typed `StatsView` leaders, and the OBS `goleadores` scene reads the hand-typed list. Nothing sums
goals and assists across the matches the game already uploaded. (This is the feature requested; see plan below.)

**F-05 · C-1 · Profile note blames the game for ratings.** `PlayerAnalysis.jsx:93` "Sin calificación: el juego no la
deja leer" is a claim we have not proven: we did not find it yet. Fix: "Sin calificación todavía." (Moot if ratings
ship.)

**F-06 · R-03 · Lineup pitch markers overlap at 360 px.** `LineupPitch.jsx` uses `w-20` labels at 6 % insets on a
68-wide vertical pitch; two centre-backs 16 lateral units apart land ~58 px apart with 80 px labels [unverified,
computed from the classes]. Fix: `w-16` + `text-[11px]` under `sm`, or truncate to 8 characters.

## LOW (Quality Locks) · motion (transitions-dev)

**F-07 · Live numbers jump.** Stat values, the clock and player counts change in place every ~3 s with no motion;
only the score flashes. transitions-dev "number pop-in" (02) for the score and "text swap soft" (34) for stat values
fits: a value that changed cross-blurs in ~180 ms. Never on first render.

**F-08 · Stat bars snap.** `StatCompareRow` bar widths change with no transition. "Card resize" (01) logic applied
to width: `transition: width var(--dur-base) var(--ease-out)`.

**F-09 · Skeleton cuts to content.** Loading `skeleton` blocks are replaced instantly. "Skeleton loader and reveal"
(14): a 150 ms cross-fade.

**F-10 · Tab content swaps without continuity.** The match tabs replace the panel instantly while the pill also
jumps. "Tabs sliding" (16) for the pill; a 120 ms fade on the panel. The mobile Jugadores list → ficha is a
list ↔ detail: "page side-by-side" (08).

**F-11 · Three `animate-pulse` live dots on one screen** (list heading, row, header). The live state is said three
times; the pulse is a Tailwind default. Keep one pulse (the row/header status), static dot in the section heading.
