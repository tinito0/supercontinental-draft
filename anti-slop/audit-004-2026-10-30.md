## HIGH (Hard Gate)

**F-01 · R-39 · The «Estilo de juego» label now labels the «¿Qué es?» button, not the select.** [measured] The
button sits inside the `<label>` before the `<select>`, so `label.control` is the button. The select has no
accessible name, the button is announced «Estilo de juego Cualquiera», and clicking the words «Estilo de juego»
opens the glossary. Fix: take the button out of the label (`<div>` row, `<label htmlFor="filter-playing-style">`,
`id` on the select).

**F-02 · R-35 · Never run in the browser and no click-through recorded.** Verification was tests, an esbuild syntax
check and a server render. The modal was never opened at 360 or 1280 px, and none of the new controls was clicked.
Fix: render `FiltrosModal` in a Playwright harness at both widths and record each control: «¿Qué es?» → opens and
reaches the glossary, «¿Qué hace cada una?» → same, positions → toggle and stop at 3, level → switches, chip →
clears, plus console and overflow checks.

**F-03 · R-38 · Glossary descriptions were written from memory and are shown as fact.** The owner was told they are
unverified, but the UI does not say so. Likely wrong, compared with PES 2021: «Atacante Extra» (the game describes
a defender who goes up late in the match, not at set pieces), «Pase a profundidad» / WeightedPass (backspin on
lofted passes, not long distance), «Patadón en corto/largo» (low or high trajectory, not near/far precision). Fix:
check them against the in-game help text and correct, or mark the unchecked ones until they are checked.

**F-04 · R-32 · «¿Qué es?» scrolls but leaves focus where it was.** A keyboard or screen-reader user stays at the
top of the dialog, and Tab continues from the old place. Fix: after the scroll, focus the glossary section toggle.

**F-05 · R-39 · The level selector claims radio behaviour it does not have.** `role="radiogroup"`/`role="radio"`
without arrow keys or roving tabindex: ARIA promises what the keyboard does not do. (The saved-filter colour picker
already has the same pattern; it is out of scope.) Fix: plain toggle buttons with `aria-pressed`, reusing
`ToggleButton` (also fixes F-10).

**F-06 · R-33 · Source files were edited with Python string-replacement scripts.** The result is plain source code
(no runtime patching), so no code needs to change. The breach is in the process. Fix: edit files in place from now
on.
